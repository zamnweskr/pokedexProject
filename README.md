# Native Dex

A Pokedex app built with React Native and Expo, available on iOS and Android.

## What it does

Native Dex lets you browse Pokemon by generation, view detailed stats, abilities, moves, and evolution chains — all powered by the [PokeAPI](https://pokeapi.co).

## Features

- **Generation selector** — choose from Gen 1 through Gen 9
- **Pokemon browser** — scrollable grid with sprites and types
- **Pokemon detail** — official artwork, stats, height, weight, and description
- **Evolution chain** — visual evolution line with conditions (level, trade, item)
- **Moves** — full move list with type, power, accuracy, and description
- **Abilities** — complete ability list with detailed descriptions

## Built with

- [React Native](https://reactnative.dev) + [Expo](https://expo.dev)
- [PokeAPI](https://pokeapi.co) — free, open Pokemon data
- [React Navigation](https://reactnavigation.org) — stack + drawer navigation
- [React Native Elements](https://reactnativeelements.com) — UI components

## Getting started

```bash
npm install
npx expo start
```
